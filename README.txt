REŽIM – Tvůj osobní kouč | verze 3 (GitHub Pages / iPhone)

NOVINKY
- Týdenní přehled je vždy od pondělí do neděle. V Nastavení se dny vybírají od pondělí.
- Běh: zapisuje se vzdálenost (km) a doba trvání (minuty); jednotlivé běhy a týdenní součty.
- Stopky: při uložení zadejte také uběhnutou vzdálenost.
- Ranní vstávání: skutečný čas + volba Splnil / Nesplnil. Volitelná výzva 12 dotyků zůstala.
- Každý den se zobrazí 3 motivující motta z knihovny 60 mott, navíc tlačítko pro další.
- Starší záznamy a nastavení z verze 1/2 zůstávají zachována ve stejném prohlížeči.
  Starší běhy bez kilometrů se nadále zobrazí s časem; vzdálenost bude 0 km, dokud
  ji nezačnete zapisovat. Nejde o ztrátu uloženého času.

INSTALACE NA GITHUB PAGES
1. Rozbalte ZIP (na GitHub nenahrávejte ZIP jako jediný soubor).
2. Nahrajte obsah složky přímo do kořene veřejného GitHub repozitáře,
   např. https://github.com/UZIVATEL/rezim – soubor index.html musí být v kořeni.
3. V Settings > Pages zvolte Deploy from a branch / main / /(root).
4. Po publikaci otevřete https://UZIVATEL.github.io/rezim/ v Safari.
5. V Safari: Sdílet > Přidat na plochu.

AKTUALIZACE EXISTUJÍCÍ INSTALACE
- Nahraďte obsah repozitáře soubory z tohoto ZIP a změny potvrďte (Commit changes).
- Po zveřejnění změn stránku v Safari znovu načtěte; případně aplikaci
  ukončete a znovu otevřete. Aktualizoval se i offline cache (v3).
- Nesmazávejte úložiště webu / data prohlížeče – jinak se mohou ztratit záznamy.
- Pro jistotu si v Nastavení REŽIMU před aktualizací stáhněte zálohu dat.

DALŠÍ FUNKCE
- Kliky, dřepy, shyby, jídlo, spánek, den bez alkoholu, záchranné minimum,
  nastavení cílů a dnů, kalendářní připomínky (.ics), export / import dat.

OMEZENÍ
- Jde o webovou aplikaci PWA, nikoli nativní iOS aplikaci z App Storu.
- Upozornění ve webové verzi fungují jen když je aplikace otevřená;
  neslouží jako spolehlivý budík. Použijte systémové Hodiny nebo Kalendář.
- Data se ukládají lokálně do konkrétního prohlížeče, ne na GitHub ani do cloudu.
- Aplikace automaticky neměří GPS vzdálenost: kilometry zadáváte ručně.
